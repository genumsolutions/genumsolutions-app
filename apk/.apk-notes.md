# APK notes (manifest)

This folder holds **every build this project has produced for the 3.x line** — the
published releases *and* the local builds that were never published. Nothing has been
deleted; each file is labelled with exactly what it is, verified from the APK itself.

APK binaries are gitignored here — only this notes file and `.gitignore` are tracked.

The identical set is mirrored into `genumsolutions-app-V4/apk/`, so if one local folder
is lost the other still has every binary.

### The 3.4.4 APK is the proof of the original release key

`genum-solutions-3.4.4.apk` carries the release certificate `86ddf34e…164945`. That is
**exactly** the certificate inside the release keystore recovered on 2026-11-25 from
`E:\Project_backup\genumsolutions-app\mobile\keystores\genum-release.jks` (alias
`genum-release`, `PrivateKeyEntry`, 2806 bytes, created Aug 29 2026).

So the recovered keystore is not "a real release key" — it is **the** original release
signing identity, proven against a shipped binary. A release-signed build made with it
**will install in place over 3.4.4**.

**Do not delete this file.** It is the only artifact that proves the keystore identity.

### Correction to earlier revisions of this file

Earlier versions claimed the published 3.4.4 had been debug-signed with SHA-1
`2fb086e5…` from a `C:\bs` build machine. That was wrong — 3.4.4 is release-signed with
`86ddf34e…`.

The real, live signing break is: **3.4.4 is release-signed, 3.4.5–3.4.8 are
debug-signed.** A device on release-signed 3.4.4 cannot install any of the debug-signed
builds (`INSTALL_FAILED_UPDATE_INCOMPATIBLE`); fresh installs are unaffected. The fix is
to ship a release-signed build with the recovered key so the installed base converges
back onto the release identity.

## Source of truth

- `mobile/app.json` — `version` + `expo.android.versionCode` (single source of truth).
- `mobile/package.json` — `version` (kept in sync by `scripts/bump-version.mjs`).
- `mobile/src/config/site.ts` — `APP_VERSION` (kept in sync by `scripts/bump-version.mjs`).
- The **bucket** `release.json` — what the phone and the website actually read.
